数据只存本地，不收集、不上传

橘子导航不设账号、不连服务器数据库。你的分类、网站、访问记录都只保存在当前浏览器里。需要换设备时，导出备份文件，在新设备导入即可，全程不经过任何服务器。

橘子导航 · 使用帮助

按主题整理的常见问题与操作说明。顶部搜索框可以实时过滤，输入关键词即可定位到相关问题。
01

快速上手

第一次使用，先了解页面上的几个主要区域。
怎么打开一个网站？
点卡片任意位置，或点卡片右侧的箭头，都会在新标签页打开。不需要找“访问”按钮，整张卡片就是入口。
顶部搜索框怎么用？
输入关键词按回车或点“搜索”，会在百度里搜索。按键盘上的 / 键可以快速把光标移到搜索框，按 Esc 退出。
搜索框获得焦点时，提示文字会消失，输入更干净；失焦且没有输入内容时会自动恢复提示。
快捷栏是什么？
顶栏左侧那一排小按钮，点一下直接打开对应网站。进入编辑模式后，可以把任意网站卡片拖到快捷栏添加，也可以点快捷项右上角的 × 移除。
快捷栏顺序目前不支持拖拽调整。想让某个网站靠前，可以先移除再重新拖入。
底部的“最近访问”是什么？
记录你最近打开过的网站，点一下就能再次打开。右侧垃圾桶按钮可以清空记录。
卡片右侧的“今日 X 次”是什么？
当天从导航页打开这个网站的次数，第二天自动归零。只有从导航页点开才会计入，直接在其他地方打开不会统计。
02

个性化设置

调整外观、顺序，让页面更顺手。
怎么切换深色 / 浅色？
点顶栏的“半圆”图标，在跟随系统 → 浅色 → 深色之间循环切换。选择会记住，下次打开保持上次的设置。
怎么换页面背景？
点顶栏的“调色盘”图标，可选三种背景：
  • 天青蓝（默认）
  • 中性灰
  • 标准灰
选择会记住。
怎么调整左侧分类的顺序？
进入编辑模式后，左侧每个分类右侧会出现 ▲▼ 按钮，点一下上移或下移一位。
怎么调整分类里网站的顺序？
  • 电脑端：进入编辑模式后，直接按住卡片拖动到目标位置。
  • 手机端：编辑模式下，每张卡片右侧有 ▲▼ 按钮，点按交换上下位置。
03

编辑与管理

添加、修改、删除网站和分类。
怎么进入编辑模式？
点顶栏的“铅笔”图标，按钮变成白底蓝字就是编辑中。再点一次退出编辑。
怎么添加网站？
编辑模式下，每个分类底部有一个“＋ 添加网站”虚线框，点它会在该分类末尾新增一张空卡片，填名称和网址即可，改完自动保存。
怎么修改网站名称或网址？
编辑模式下，卡片会变成两个输入框，直接改，改完自动保存，不需要额外的“保存”按钮。
怎么删除网站？
编辑模式下，点卡片右侧的红色 × 按钮。删除后立即生效。
怎么重命名分类？
编辑模式下，分类标题会变成输入框，直接改，改完自动保存。
怎么删除分类？
编辑模式下，点分类标题右侧的 ×，会弹出确认提示。确认后整个分类和它下面的所有网站一起删除，操作不可撤销。
怎么新增一个分类？
目前页面上没有“新增分类”按钮。如果确实需要新分类，有两种方式：
  • 在编辑模式下重命名一个现有分类，改造成你需要的分类；
  • 导出一份 JSON，手动编辑加上新分类后再导入。
后续版本可能会补上“新增分类”按钮。
手机端怎么编辑？
左上角菜单打开侧栏，点铅笔进入编辑模式。卡片右侧会出现 ▲▼ 按钮调整顺序，删除和修改都在卡片上完成。
04

数据与隐私

橘子导航不设账号同步，你的数据只存在本地浏览器里。
我的数据存在哪里？
只存在你自己浏览器的 localStorage 里。不上传服务器，不经过任何第三方，换浏览器、清缓存、换电脑都不会自动同步。
为什么不提供账号同步？
账号同步意味着你的书签、分类、浏览习惯都要存到服务器上。服务器一旦被攻击、内部泄露、或者运营方出问题，你的数据就可能暴露。
我们的选择

不收集、不上传、不设账号。你的数据始终在你自己手里，从源头避免服务器风险带来的隐私暴露。

换电脑、换浏览器怎么办？
用导出备份 + 导入备份的方式手动同步：
  • 在旧设备点顶栏“下载”图标，导出 JSON 文件；
  • 把 JSON 文件通过 U 盘、网盘、邮件附件等方式带到新设备；
  • 在新设备打开导航页，点“上传”图标导入 JSON 文件。
整个过程数据不经过任何服务器，文件由你自己保管。
服务器出问题会影响我吗？
不会。你的数据不在服务器上，服务器只提供网页代码。即使网站下线，你本地的数据还在，之前导出的备份文件也还在。
数据会不会泄露？
只要不把导出的备份文件发给不可信的人，就不会。建议定期导出备份，避免浏览器清理缓存导致数据丢失。
清理浏览器缓存、使用无痕模式、重装系统都会清空 localStorage，记得定期导出备份。
怎么备份数据？
点顶栏“下载”图标 → 导出 JSON，会下载一个 橘子导航-日期.json 文件，保存到你信任的位置。
怎么恢复数据？
点顶栏“上传”图标 → 选择之前导出的 JSON 文件。
导入是覆盖式的，会替换当前全部分类和网站。导入前建议先导出当前数据做一份备份。
导出的 JSON 文件能做什么？
备份、迁移到另一台电脑、手动编辑分类和网站、分享给朋友。JSON 是纯文本格式，用记事本就能打开和修改。
05

链接检查

检查所有网站是否还能正常访问。
怎么检查链接？
进入编辑模式后，顶栏会出现“心跳”图标，点它，确认后开始检测所有网站是否可达。检测过程可能需要 1–2 分钟。
为什么有些网站显示“未知”？
受浏览器 CORS 限制，政府、内网、部分反爬站点无法从网页端直接检测，会显示“未知”，不代表链接失效，建议手动打开确认。
检查结果里可以直接删除吗？
可以。结果面板里每条右侧有 ×，点它确认后会把该网站从导航里彻底删除。
06

其他功能

底栏和一些细节功能。
底栏的年度进度是什么？
显示今年已经过去多少百分比。鼠标悬停能看到具体已过多少天、还剩多少天。
下班倒计时怎么用？
底栏显示距离下班还有多久。点一下可以在 17:00、17:30、18:00、18:30、19:00、21:00 之间切换下班时间，选择会记住。周末会显示“周末愉快”，下班后会显示“已下班”。
收藏按钮是干嘛的？
点星标会尝试把当前页加入浏览器收藏夹；浏览器不支持时，会复制链接并提示你按 Ctrl+D（Mac 为 Command+D）手动收藏。
有哪些键盘快捷键？
  • / 聚焦搜索框
  • Esc 关闭弹窗、退出搜索框、关闭手机侧栏
07

常见问题

遇到问题先看这里。
点卡片没反应？
检查是不是在编辑模式。编辑模式下点卡片不会打开网站，只会进入编辑。
为什么有些网站打不开？
可能是网络问题、网站本身故障、或者需要登录 / 代理。可以先用健康检查看看状态，再用浏览器直接访问确认。
为什么今日访问次数不更新？
次数只统计从导航页点开的记录，直接在其他地方打开不会计入。另外刷新页面后计数仍然保留，直到第二天归零。
手机端为什么看不到左侧分类？
手机端侧栏收进了左上角菜单，点汉堡按钮（三条横线）打开，选完分类会自动关闭。
导入后数据不对？
导入是覆盖式的，会替换当前全部分类和网站。如果导入错了，可以重新导入之前导出的备份文件恢复。所以导入前一定要先导出当前数据。
数据突然没了？
常见原因：清理了浏览器缓存、使用了无痕模式、换了浏览器或设备、重装了系统。这些都会清空 localStorage。建议定期导出备份，放在你信任的位置。
